# 组织知识与可复用能力

XTeam 保存组织自己的知识、SOP、Skill 与工作流程。成员可使用网页、CLI 或 MCP；连接器可替换，资料可导出，不要求飞书或钉钉账号。

## 从知识到团队方法

1. 创建知识空间，将背景、介绍和调研整理为有稳定链接的页面。页面可分层，支持标题与正文搜索。
2. 将可重复使用的方法写为 SOP 页面，明确适用场景、输入、步骤与验收。保存后选择“保存为 Skill”。
3. 为本地 Skill 填名称和适用场景，正文以标准 `SKILL.md` 保存；保留原 SOP 的页面 ID 和版本。
4. 将选定 Skill 绑定到 Agent，或组合成有序工作流程的步骤。绑定保存当时的版本快照，来源更新时提示有更新，不静默替换。
5. 导出空间、Skill、Agent 上下文或工作流程，交由外部工具使用。空间包保留页面原文、历史、原件、Skill 与相关绑定；CLI 另生成可独立阅读的 Markdown 和文件目录。

当前工作流程保存指令和配置，由外部工具接续；没有内置执行引擎或付费模型调用。首版每个独立部署服务一个企业内部团队，沿用所有成员可读写的边界；没有跨企业共享或空间权限隔离。附件内容不做 OCR 或全文提取，搜索覆盖页面标题和正文。

## 页面与原件

页面更新必须携带读取时的 `expected_version`。冲突时保留草稿，先读取并合并最新内容；历史恢复也生成新版本，不抹除原有历史。归档保留原文和历史，恢复父页面后可恢复子页面；归档有未归档子页面的父页面会被拒绝。

原件附件单件最多 8 MiB，存入 SQLite，与知识一起备份。只允许登录成员或有效个人令牌读取；相同页面、文件名和内容摘要的重试返回同一附件。图片按文件头识别，其他文件以下载原件方式提供，不执行其中内容。

## 接口与迁移

知识 API 位于 `/api/wiki`；页面、空间、搜索、历史、附件、SOP 转 Skill、Agent 绑定、工作流程和导出共用服务规则。CLI 与 MCP 使用个人令牌，网页使用会话与 CSRF。带有不匹配浏览器 Origin 的请求仍会被拒绝。

已有项目、链接、Agent 和 Skill 保留。知识 schema 增量建表，现有数据表不重建。日常知识维护使用新入口；旧项目和 Todo 接口仅用于过渡兼容。设置 `XTEAM_TODOS_RETIRED=1` 后隐藏旧项目导航、关闭 Todo 写入并移除其通用 MCP 工具。

旧 Todo 通过独立管理员迁移工具处理。先 `plan` 保存包含原编号、UUID、说明、状态和更新时间的清单，再 `apply` 以新的 SQLite 在线备份为前提核对并归档；清单变化则原子停止。原记录完整保存在归档表，活跃 Todo 删除。恢复按批次保留原 ID，不覆盖新页面或已存在任务。工具见[CLI 文档](cli.md#管理员旧任务迁移)。
