## 多 Skill 导入（2026-10-30 本地追加）

“从 URL 导入”支持仓库根或父目录：先只读发现候选，再勾选或全选导入。每项保留独立正文、附属文本和精确目录来源，刷新不会导入兄弟或嵌套 Skill。单个精确来源保持原流程。

候选和导入绑定同一个 Git 树 SHA。最多 20 个候选、每批最多 20 项/32 MiB 文本；沿用单文件 1 MiB、单 Skill 8 MiB/256 个附属文件限制。超限明确拒绝，不截断候选。已有同名条目默认暂停，可逐项跳过、重命名或确认覆盖；部分失败保留成功项，重试只提交未成功项。网页和 [MCP 工具](mcp.md)共用服务，不安装或运行来源内容。

此为初始本地追加范围，后由PR #13发布、PR #15修复限流并补齐匿名真实域名验收。初始已认证gh只读验证不能代替生产匿名验收；上述历史DNS阻塞事实保留，未放宽公网校验。
