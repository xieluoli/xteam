# 功能与验收基线

MUL-265 已确认：独立重写、一个共享团队、管理员预设邮箱密码账号；Project 仅是逻辑项目，存简介和链接；模板/Skill Markdown CRUD；网页和 MCP 都可维护 Todo。旧环境和数据保留，新版使用独立空数据库。

本版包括个人改密、退出、MCP 令牌创建/撤销、名称查找、正文复制、错误保留输入、项目聚合详情和 Todo 结果说明。管理员通过命令创建/重置/禁用账号，不做管理后台。

验收主流程：成员网页登录建项目 → 写简介、关联链接、Todo → 建模板/Skill → MCP 客户端读取上下文及正文 → 在外部完成工作 → 回写 Todo 结果/状态 → 另一成员查看 → 应用重启仍保留。

不包括：Agent 执行、外部 MCP 客户端、文件目录、第三方文档抓取、多团队、指派、审批、复杂任务流、旧 API/数据迁移、验证码或 Resend。

成员对全部业务资源可读写；修改自己密码、管理自己令牌。非成员不可进入。禁用使会话、令牌失效。删除项目不影响其他项目或团队模板/Skill。

2026-10-27 用户追加授权：无需中途审批，完成 GitHub 推送和 VPS 重部署，目标域名 `xteam.space01.cc`；可备忘跳过复杂非主流程。不授权删除旧数据库、强推或清空 Git 历史。

## MUL-266：Skill 来源与详情

用户批准在原 Skill 板块上对齐参考功能，并明确不支持 ClawHub。仅支持公开 GitHub 仓库、tree 目录、blob SKILL.md 与 skills.sh URL；不支持手动新建、本地/ZIP 导入、runtime 复制、Used by 或 Agent 绑定。URL 导入及刷新包含正文和附属 UTF-8 文本文件，不执行任何内容。

新增表格、添加者/标签筛选、名称/更新时间排序、行菜单、单选/多选来源更新及删除、逐项结果。独立详情的 Overview 编辑名称/简介/标签，Files 提供目录树、安全 Markdown 预览、源文本编辑及附属文件维护；名称和简介与 YAML frontmatter 同步。旧 Skill 保留，无来源时不能来源更新，不伪造添加者。

所有成员继续同权。更新前确认覆盖本地正文/文件；同名默认冲突，明确选择覆盖、重命名或跳过。限制单文件 1 MiB、全包 8 MiB、256 个附属文件；拒绝越界路径、非公开来源、内网 DNS 地址和 HTTP 重定向。大型或多 Skill 仓库无法唯一定位时明确报错，不任意选取。

本次授权 `yaml`、`react-markdown`，未引入 ZIP 依赖。用户后续明确“接入”，追加授权先为 Skill 接入 Tailwind v4/shadcn，后明确要求所有页面不再用自写基础 UI；现已覆盖共享侧栏、登录、项目、模板、Skill、MCP 及全部弹窗，范围见[组件接入说明](skill-components.md)。未授权提交/推送、PR、生产数据操作或部署；本节不继承 MUL-265 的发布授权。
