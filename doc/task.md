更新：2026-10-31（Asia/Shanghai）；共享接续入口，历史按日期保存。文档快照不等于代码、平台或线上状态已同步，开始前须按[跨设备接续](handoff.md)核对远端。

## 北极星

XTEAM 保存团队项目与任务的关键上下文，让任意设备上的外部 agent 能快速理解任务、继续工作，并留下下一次接续所需的结果。

价值链：获取上下文 → 理解任务 → 外部工作 → 回写结果 → 跨设备接续。

## 阅读与记录

1. 每次先读本文件、[工作约定](workflow.md)、[lessons](lessons.md)、[code-standards](code-standards.md)及主目录AGENTS.md。
2. 获取实际北京时间日期，读取或建立对应daily/YYYY-MM-DD/task.md及review.md；继续读取最近一次实际完成的复盘。格式见[每日记录说明](daily/README.md)。
3. 完整计划/执行写当日task，实际复盘写当日review；本文件只更新当前状态和活跃任务指针，不追加每日流水。
4. 跨日沿用原任务ID，链接原始范围并记录变化；同日重试接续同一文件。创建计划/空复盘不增加执行日或复盘次数。
