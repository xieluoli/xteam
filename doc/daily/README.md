# XTEAM 按日记录

[主入口](../task.md) · [工作约定](../workflow.md)

```text
doc/
  task.md                  当前状态、未完项、日期入口
  handoff.md               多设备起手、认领与进度回写
  workflow.md              稳定工作流程
  lessons.md               去重后的长期教训
  code-standards.md         现行硬规则
  daily/
    YYYY-MM-DD/
      task.md              当日计划、批次与执行结果
      review.md            当日实际复盘
```

日期统一Asia/Shanghai。主入口不列完整历史索引；按日期目录查历史，启动只读当日和最近已完成复盘。doc/随Git共享；原始日志、diff、截图仍放各设备.local/xteam-cycle/，只共享脱敏结论和证据索引。历史本地证据不随Git转移，无法读取时注明未复验。

## 当日task最少包含

- 日期、实际开始/结束或未执行状态；负责设备/agent标识、源码分支、起止HEAD及代码是否已推送。worktree绝对路径只在设备.local记录。
- 计划表：稳定ID、类型/价值、范围与依据、验收、验证、依赖和状态；跨日任务链接原始范围。
- 各批次的实际变更、测试结果、取消/阻塞及返工差异，不重复贴完整历史说明。
- PR URL、最终head/merge/部署SHA、CI、备份/回退、线上请求及截图清单；缺项明确标待验。
- 当日结束状态与下一次接续；试跑按实际执行日期去重。

## 当日review最少包含

- 状态和实际复盘时间、当日task链接、审阅游标。未运行就写待复盘，不预写成功。
- 本地开发/发布/线上验收逐项核对，明确实际交付与缺口。
- 返工和独立教训的规则/原因/证据；合并同根因，再更新长期表中的计数与索引。
- 平台状态对账、次日已确认计划或决策点，第三日试跑结束与暂停结果。

## 维护规则

- 同日续跑复用两个文件，按任务/批次更新，保留不同证据链接。
- 跨日只接续未完项；不改历史完成口径，不因重试、专项或建文件增加天数。
- 已封存日期只补事实纠正并注明时间；不把新一天工作写进旧日期。
- 主task只维护活跃项与最新链接；memory覆盖更新检查点；稳定规则编辑原条目。
- 结束先fetch核对其他设备新进度，再同步批准范围内的文档分支/PR与平台状态；见[多设备接续](../handoff.md)。本机锁不是跨设备互斥，已有认领先协调。

## 夜间复盘格式

### YYYY-MM-DD（Asia/Shanghai）

- 日期范围：按本地 00:00 至次日 00:00，并记录上次游标以来尚未回放的变更；重试不重复复盘。
- 代码证据：起止 HEAD、commit 列表（没有就写无）、本日差异快照与上次快照之间的变化、测试输出路径。
- 实际交付：完成/未完成/取消及验收结果；不从提交标题猜测行为。
- 踩坑与返工：先失败/误判 → 原因 → 修复 → 复验；无新事件写无新增。
- 教训：规则 / 原因 / 证据 / 独立事件 ID / 累计次数 / 是否升级。
- 次日调整：新增/延后/取消任务的依据；同步 task.md。
- 试跑统计：不同执行日计数、实际 feat、返工、验证缺口及用户需决策事项。
